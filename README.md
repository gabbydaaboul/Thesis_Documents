# Thesis_Documents
This repository contains all of the documents relating to my university thesis.

Daaboul_Gabriella_Thesis - Contains the theory used to develop the analysis models, as well as a comparison of the results obtained from each analysis model. 

EulerAndTimoshenkoLinearAnalysis - A script that calculates the displacement for a beam with a rectangular cross section using either Euler Bernoulli beam theory or Timoshenko beam theory. The analysis is linear elastic.

EulerNonLinearAnalaysis - A script that calculates the displacement for a beam with a rectangular cross section using Euler Bernoulli beam theory. The analysis is non linear.

eulerMatrix - A function used within the EulerAndTimoshenkoLinearAnalysis script. It is used to determine the stiffness and loading matrix of each element of the beam for the analysis using Euler-Bernoulli beam theory.

timoshenkoMatrix - A function used within the EulerAndTimoshenkoLinearAnalysis script. It is used to determine the stiffness and loading matrix of each element of the beam for the analysis using Timoshenko beam theory.

eulerNonLinearMatrix - A function used within the EulerNonLinearAnalysis script. It is used to determine the stiffness and loading matrix of each element of the beam for the analysis using Euler-Bernoulli beam theory, accounting for material nonlinearity.
